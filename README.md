# Bilibili 广告跳过助手

中文 | [English](README_EN.md)

一款智能的Chrome/Firefox浏览器插件，通过多信号源分析自动识别B站视频中的嵌入式广告段，并提供自动或手动的跳过功能。

## 功能特点

- **多信号识别**: 综合视频章节、简介、字幕和弹幕，交叉核对广告内容与起止边界
- **按置信度跳过**: 高置信度区间可自动跳过；低置信度或来源冲突时显示按钮，等待手动确认
- **多段支持**: 分别处理视频中的独立广告段，保留段落之间的正文，每段只自动跳过一次
- **手动跳过**: 在广告段显示跳过按钮，用户可选择性跳过
- **自定义快捷键**: 支持设置键盘快捷键，在手动模式下一键跳过广告
- **模式切换**: 支持在自动和手动模式间自由切换
- **轻量高效**: 无后台常驻，不影响页面性能
- **界面友好**: 美观的跳过按钮和设置界面

## 工作原理

插件在本地识别候选区间，再根据内容和边界证据决定是否允许自动跳过：

1. **明确章节与简介标记**: 使用UP主标注的广告区间；讨论广告的普通标题、否定表述不会直接获得自动跳过权限。
2. **观众填写的跳过时轴**: 解析与“跳过广告”“空降”“跳伞”等指令紧邻的时间。普通时间引用、重复裸时间只作为待确认线索。
3. **字幕内容与完整段落**: 结合赞助开场、持续推广、回归正文、章节边界和弹幕终点，寻找一个或多个完整区间。“免费”“搜索”“购买”等普通词本身不能确定广告。
4. **来源交叉核对**: 明确弹幕终点优先于零散字幕关键词推断；若终点与回归正文、持续推广或其他明确时轴冲突，相关结果需要手动确认。

仅关键词命中、边界不明或其他低置信度结果不会静默自动跳过。短赞助声明和视频本身的产品主题不等同于独立插入广告。控制台日志会记录检测来源、命中证据、确认要求和实际跳转。

## 安装方法

### 方法一：商店安装（推荐）

| 浏览器 | 安装步骤 |
|--------|----------|
| **Chrome** | 1. 打开 [Chrome Web Store](https://chromewebstore.google.com/detail/ecpppfmdhkopohdmplcafmbfoggijcpe)<br>2. 点击 **「添加至Chrome」** |
| **Firefox** | 1. 打开 [Firefox 附加组件](https://addons.mozilla.org/en-CA/firefox/addon/bilismartskip/)<br>2. 点击 **「添加到Firefox」** |

### 方法二：开发者模式安装
1. 下载本仓库 `master` 生产分支的源码，或解压正式扩展安装包；不要把 `test-branch` 当作生产扩展下载。
2. 打开Chrome浏览器，进入 `chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择直接包含 `manifest.json` 和 `scr/` 的目录。扩展运行只需要这两项；测试、评估和采集工具位于测试分支，不参与安装。

商店链接对应已发布版本；本地源码修复不会自动更新商店中已安装的扩展。更新本地文件后，在扩展管理页点击“重新加载”，再刷新视频页面。

## 使用方法

### 基本使用
1. 安装插件后，打开任意B站视频页面
2. 插件会读取可用的章节、简介、字幕和弹幕，在本地识别候选区间
3. 根据设置的模式：
   - **自动模式**: 仅高置信度区间自动跳过；疑似区间仍需点击按钮确认
   - **手动模式**: 在候选区间显示跳过按钮，点击即可跳过

### 切换模式
1. 点击浏览器工具栏中的插件图标
2. 使用开关切换"手动"和"自动"模式
3. 设置会自动保存并在所有标签页生效

### 设置跳过快捷键
1. 点击浏览器工具栏中的插件图标
2. 在"跳过快捷键"区域点击"设置"按钮
3. 按下想要的快捷键组合（如 `Alt + S`）
4. 快捷键会自动保存，在手动模式下按下即可跳过广告
5. 如需取消快捷键，点击"重置"按钮即可

## 支持的时间格式

插件可以识别弹幕中的多种时间格式：

- **数字格式**: `5:30`、`10:45`
- **中文数字**: `五分三十秒`、`十分钟`
- **混合格式**: `5分30秒`、`10.5分钟`
- **编码格式**: `705工程`、`0705工程`（观众常用的时间编码）

解析出时间不等于允许跳过；插件还会检查附近的跳过意图、区间有效性及其他来源的边界证据。

## 项目结构

```
BiliSmartSkip/
├── scr/                    # 源码文件夹
│   ├── constants.js        # 关键词词库与配置常量
│   ├── utils.js            # 工具函数（日志、时间格式化、中文数字转换）
│   ├── api.js              # API 请求与 Protobuf 弹幕解码器
│   ├── detectors.js        # 章节、简介、字幕和弹幕检测与置信度判断
│   ├── segment-detector.js # 完整广告区间与多来源边界核对
│   ├── skipper.js          # 跳过按钮 UI 与倒计时逻辑
│   ├── content.js          # 主入口：初始化、生命周期、检测管道
│   ├── popup.html          # 插件弹窗界面
│   ├── popup.js            # 弹窗交互逻辑
│   └── icon.png            # 插件图标
├── LICENSE                 # 开源协议
├── README.md               # 项目说明文档（中文）
├── README_EN.md            # 项目说明文档（英文）
└── manifest.json           # 插件配置文件
```

## 权限说明

- `storage`: 保存用户的模式设置和快捷键配置
- `https://www.bilibili.com/*`: 访问B站视频页面
- `https://api.bilibili.com/*`: 获取视频信息、章节标记和字幕数据
- `https://comment.bilibili.com/*`: 获取弹幕数据
- `https://i0.hdslb.com/*` / `https://aisubtitle.hdslb.com/*`: 获取字幕文件

## 隐私保护

- 本插件不收集任何个人信息
- 所有数据处理均在本地进行
- 仅访问B站公开的视频信息、字幕和弹幕API
- 不会向第三方服务器发送任何数据
