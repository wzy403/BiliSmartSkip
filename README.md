# Bilibili 广告跳过助手

中文 | [English](README_EN.md)

一款智能的Chrome/Firefox浏览器插件，通过多信号源分析自动识别B站视频中的嵌入式广告段，并提供自动或手动的跳过功能。

## 功能特点

- **多信号智能识别**: 综合视频章节、简介、字幕、弹幕等多种数据源，精准识别广告段落
- **自动跳过**: 支持自动跳过广告段，无需手动操作
- **手动跳过**: 在广告段显示跳过按钮，用户可选择性跳过
- **模式切换**: 支持在自动和手动模式间自由切换
- **轻量高效**: 无后台常驻，不影响页面性能
- **界面友好**: 美观的跳过按钮和设置界面

## 工作原理

插件通过多信号检测管道识别广告段，按置信度从高到低依次尝试：

1. **视频章节标记**: 读取UP主设置的章节分段，匹配广告关键词
2. **视频简介时间戳**: 解析简介中的时间戳列表，识别标注为广告的段落
3. **字幕内容分析**: 获取AI/人工字幕，通过关键词聚类检测广告段；支持字幕与弹幕跨层联合定位
4. **弹幕时间格式解析**: 分析弹幕中的时间标记（如"5:30"、"五分三十秒"、"705工程"等）
5. **弹幕关键词匹配**: 使用方向性关键词（开始类/结束类）进行双向锚定

任意一层命中即触发跳过，后续层作为兜底保障。

## 使用方法

### 基本使用
1. 安装插件后，打开任意B站视频页面
2. 插件会自动在后台分析弹幕，识别广告段
3. 根据设置的模式：
   - **自动模式**: 检测到广告段时自动跳过
   - **手动模式**: 显示"跳过广告"按钮，点击即可跳过

### 切换模式
1. 点击浏览器工具栏中的插件图标
2. 使用开关切换"手动"和"自动"模式
3. 设置会自动保存并在所有标签页生效

## 支持的时间格式

插件可以识别弹幕中的多种时间格式：

- **数字格式**: `5:30`、`10:45`
- **中文数字**: `五分三十秒`、`十分钟`
- **混合格式**: `5分30秒`、`10.5分钟`
- **编码格式**: `705工程`、`0705工程`（观众常用的时间编码）

若无法通过时间格式识别广告段，插件会依次尝试字幕分析和关键词匹配等方式进行识别。

## 权限说明

- `storage`: 保存用户的模式设置
- `https://www.bilibili.com/*`: 访问B站视频页面
- `https://api.bilibili.com/*`: 获取视频信息、章节标记和字幕数据
- `https://comment.bilibili.com/*`: 获取弹幕数据
- `https://i0.hdslb.com/*` / `https://aisubtitle.hdslb.com/*`: 获取字幕文件

## 隐私保护

- 本插件不收集任何个人信息
- 所有数据处理均在本地进行
- 仅访问B站公开的视频信息、字幕和弹幕API
- 不会向第三方服务器发送任何数据
