# 先读内容，再对照算法

这是 2026-10-04 的助手内容审核，不是用户人工标签。三个独立审核上下文分别完整阅读 16 个视频的缓存字幕；输入只有 BV、CID、标题、时长、简介及全部字幕，不含检测结果、弹幕、社区时轴、旧标签或选样分组。审核结果完成后才解除预测隐藏，进行算法诊断。主审负责选样和比较，之前已接触过算法结果，因此不声称整个实验完全双盲。

## 范围与文件

- `batch-1.json`、`batch-2.json`、`batch-3.json`：48 个视频、17,918 条字幕的全文内容判断、广告/保留决定、原文证据、拟议边界及不确定范围。
- `selection.json`：28 个当前自动跳过且有字幕的视频；从 36 个有字幕、自动跳过被取消的视频中按固定 SHA-256 排序选 12 个；从其他无自动跳过、无人工标签的视频中同法选 8 个。控制组指算法行为不同，不预设无广告。
- `freeze.json`：审核完成、首次对照后，运行时试验之前记录的审核文件和原始字幕输入哈希。此后不随算法结果改标签。
- `visual-supplement.json`：另一个没有本机字幕的 B 站视频 `BV1QnuH66Ezq`，阅读简介所指原视频的完整英文字幕，并抽点核对 B 站烧录字幕和画面。它只支持广告性质与大致位置，不加入 48 条的秒数评分，也不补入算法输入。

缺字幕的 `BV11H4y1c7gh` 本轮尚未完成内容核验。原 15 个人工标签原样保留，助手起点与人工原范围不同之处单列解释，不覆盖用户决定。

## 计分原则

1. 广告性质、是否应跳、是否完整、是否误跳正文分别判断。短赞助声明及主体商品评测可以保留；混入剧情揭晓的广告跳过决定可以未知。
2. `normalSpeechRanges` 仅解释已读正文口述；计分必须与真实字幕行时间求交。没有字幕的空隙、未审核或待定内容一直是未知，不当负例。
3. 广告铺垫与最后引导保留在拟议完整范围中，不向内裁五秒或只评分末尾 CTA。完整覆盖按一个原始预测与一个原始拟议范围比较，不能拼接碎片。字幕参考不是逐帧视觉边界，完整度也是对参考的一致性。
4. 自动跳转使用回放记录的真实 seek（包括 `end + 0.05`），候选与自动分别统计。完整覆盖广告不代表没有多跳正文。
5. 已知边界存在语义争议，所有结论限于本轮参考。这批视频已参与开发，又富集了广告和算法变化，不能外推全站准确率或取消的 112 个区间全都正确/错误。
