# 标注版本与跳过语义

本目录随独立测试分支保留，不进入插件生产包。标签用于离线计分和人工审核；`evaluate-segments.cjs` 在调用检测器前移除标签及社区参考，检测规则不会读取人工起止点、备注或 BV 对应答案。

## 内容性质与跳过决定

两套独立字段描述不同问题：

| 字段 | 值 | 含义 |
| --- | --- | --- |
| `contentType` | `ad` / `non_ad` / `uncertain` | 是否属于广告内容 |
| `contentConfidence` | `high` / `uncertain` | 对内容性质的置信度 |
| `skipDecision` | `skip` / `keep` / `uncertain` | 所选范围应跳过、应保留或待定 |
| `skipConfidence` | `high` / `uncertain` | 对跳过决定的置信度 |
| `boundaryConfidence` | `high` / `uncertain` | 对所选决定范围起止的置信度 |

广告可以 `keep`；内容未知也可以明确 `keep`。评估只按跳过轴确定正负，内容置信度不会降低一个明确保留决定的效力。边界置信度独立保存，不代表已经逐帧核对画面中的商业边界。

`semantics.js` 统一解释标签并派生兼容字段：`skip→label:ad`、`keep→label:normal`、待定→`label:uncertain`，`confidence=skipConfidence`。因此兼容字段 `normal` 表示应保留，不能证明不存在商业关系。旧 `ad` 映射为广告且应跳过；旧 `normal` 映射为内容未知且应保留；旧不确定仍不确定。`validate.cjs` 校验文档、来源和范围，并提供作者划分策略。

备注只保存解释，不通过正则或关键词自动覆盖结构化决定。`evidence` 有时引用区间外的正文转场句来解释边界，引用文本不能自动继承整段标签。

## 原始人工反馈与双轴迁移

- `human/review-2026-09-30-v1.json`：用户从审核页导出的原始快照，14 个视频、13 位作者、25 段。旧格式为 12 段应跳过、12 段应保留、1 段不确定。原文件保持不变。
- `human/review-2026-09-30-v2.json`：依据用户要求、原始按钮确认和明确备注生成的双轴版本。仍为相同的 14 视频、25 个范围；没有扩大到全片或生成未审核区间。

v2 的跳过目标为 **12 段应跳过，共 679.732 秒；13 段应保留，共 452.128 秒**。其中 3 段是广告内容但应保留：商品主题试吃的两个已标范围，以及开头 `0:00.08–0:02.40` 的独立赞助声明。课程引言被明确标为非广告且应保留；其他旧正常范围的商业性质仍未知。

短声明由旧待定改为 `keep/high`，依据用户“可不用跳过”的说明。其 `boundaryConfidence=high` 确认的是所选 2.32 秒应保留，不声称完整广告视觉边界已核对；原字段和解释保存在 `semanticMigration` 中。

可重现迁移：

```sh
node eval/labels/migrate-human-v2.cjs
node --test eval/labels/*.test.cjs
```

迁移脚本仅接受冻结 v1 的指定哈希；v2 已存在且相同则验证通过，若内容不同则拒绝覆盖。它是这个版本的可追溯解释，不是运行时备注分类器。

14 条 `reviewComplete=true` 只表示本轮核对完成，全部仍为部分审核。显式区间之外保持未知；完成状态、没有检出广告或没有社区参考，都不能代替人工 `keep` 标签。新增人工反馈应另存有版本的新文件，不回写原始快照，也不将助手建议自动升级为人工确认。操作见[审核页说明](../review/README.md)。

## 助手建议与冻结挑战

`assistant-seed-v2.json` 保留开发期间的完整助手建议：40 个视频、39 位作者、104 段，均来自 development / legacy-development。包含 32 段高置信应跳建议、66 段高置信应保留建议和 6 段类别不确定建议；32 段应跳建议中 12 段边界明确、20 段边界不确定。旧字段经双轴解释后，不把 `normal` 当作商业性质已确认。

这些建议来自连续字幕阅读，保留完整介绍、交易入口及前后主题转换，而非只选关键词命中的句子。它们没有经过用户全部确认，也不是逐帧视频真值。已获得人工反馈的视频应展示人工版本；原助手文件保留出处，不直接覆盖或改名成人工标签。

`assistant-challenge-v1.json` 是独立冻结的助手挑战参考，10 个视频、21 段，与这批人工反馈作者分开。回放器检查身份和作者隔离，单独报告参考一致性，不混入人工指标；未知和不确定范围不当负例。此前全语料曾自动回放，不能称原始数据从未被触达，也不能据保留集结果继续调本轮规则。

上述助手标签均为 `kind: assistant-provisional`，不是独立人工准确率的分母。`assistant-seed-v2.json` 用于审核建议，不由当前生产回放默认加载为人工评分标签。

## 指标分母

`coverage.cjs` 只评分 `skipConfidence=high` 的 `skip` / `keep` 时间。边界不确定的范围向内各收 5 秒，仅保留剩余内部时间；为空则不计。内容未知不排除明确 `keep`，相互矛盾的 skip/keep 重叠会报错。

- TP：预测跳过与已标应跳过时间的交集；FN：已标应跳但未覆盖的时间。
- FP：预测跳过与已标应保留时间的交集；TN：已标应保留且未被预测覆盖的时间。
- precision = TP / (TP + FP)，recall = TP / (TP + FN)，accuracy = (TP + TN) / 已知秒数；F1 和 specificity 使用相同的秒数分母。分母为零时为 `null`。
- 未标注预测时间另列，不加入 TP/FP/TN/FN。全部候选与实际自动跳转分别评分。
- 完整段指标只使用边界明确的原始应跳段，要求一个原始预测覆盖至少 90%，不拼接碎片。

这批人工范围是主动挑选、用于诊断和开发的样本。同一批数据上的前后改善不是独立泛化准确率，也不能估计平台总体误跳率。助手挑战一致性、人工确认效果和未标注诊断始终分别报告。
