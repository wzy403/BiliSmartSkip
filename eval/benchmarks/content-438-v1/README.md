## 固定评分

评价全部候选标记，主要结果不按自动/手动拆分。一个原始标记只能匹配一个原始应跳广告，起点和终点分别允许前后 5 秒，且必须相交；无 90% 附加门槛，不缩短参考、不拼接碎片、不重复记功。

正确率 = 合格标记数 / 所有标记数。误标正文比例 = 标到广告边界容差以外已知应保留内容的标记数 / 所有标记数；不是全站无广告视频误报概率。广告可以应保留。部分广告/边界偏差、完全漏检、未知范围分别记录。

“广告基本跳完整的视频数”要求所有确认应跳广告均匹配，且没有其他未决应跳判断；不意味着该视频没有额外错误标记，后者由误标统计检查。候选正确率不等于自动跳转正确率，报告另存自动区间和实际 seek。

`boundaries` 给出每段广告原始起止、单个最匹配标记、开头/结尾偏差和漏掉秒数；完全没有相交候选时为 null，不能当作零误差。
